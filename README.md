# Planzoid

**Plan your launch. Prepare every post. Learn what worked.**

> Logo is a placeholder.

Plan campaigns on a calendar. Prepare every post to each platform's format.
Post by hand, or through an optional connector. Collect results and learn
what works. Local-first, works fully without a language model, and any
agent can drive it through MCP.

**Status:** plan stage, no code yet. Built in public from day one.

**Feedback wanted:** is this a problem you have? Is the plan right? Open an
issue or start a discussion. If nobody needs it, it won't be built.
